# Badge

## Purpose
Badge communicates a compact status or classification.

## Anatomy
A non-interactive text label inside a restrained status surface.

## Required and optional elements
Text children are required. `variant` is optional and defaults to `neutral`; supported values are `neutral`, `informational`, `success`, `warning` and `error`.

## Behaviour
Badge is static and has no keyboard behaviour.

## Accessibility
Use meaningful text so colour is never the only status cue. Add surrounding context or an accessible label when a short label would otherwise be ambiguous.

## Usage guidance
Use for payment, task, account or processing states and compact classifications.

## Anti-patterns
Do not use Badge as a button, link, long explanation or decorative colour chip.

## Related components
Use Alert for feedback that requires more attention or supporting detail.
